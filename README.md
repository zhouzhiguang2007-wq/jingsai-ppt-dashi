# 竞赛ppt大师

根据实际竞赛 PPT 制作和改稿反馈整理的 Codex Skill。以现有原稿为起点，确认文字、背景和证据素材的保留边界，逐页优化信息结构、箭头和图形，并渲染验收。

融合了 [PPT Master](https://github.com/hugohe3/ppt-master) 的部分 PPTX 结构解析思路：可独立读取主题、原生形状、图片引用和母版关联素材，检查优化前后的素材变化。完整 PPT Master 引擎作为可选进阶工具，未塞入上传包。代码来源与 MIT 许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。
